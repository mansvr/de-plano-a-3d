# De plano a 3D · IRVS Studio (v2)

Versión en español del hub [Flat to 3D](https://github.com/Sam1983Aing/flat-to-3d).

- **Entrada:** [http://localhost:8000/v2/](http://localhost:8000/v2/) (con el servidor local en la raíz del repo)
- **Inglés:** [../index.html](../index.html)
- Las demos cargan con `?lang=es` para textos de interfaz en español; códigos de lámina y etiquetas CAD se mantienen en inglés donde aplica.

**Crédito:** Experiencia presentada por **IRVS Studio**, basada en el proyecto open source de Samnang Aing (MIT).

## Vercel

Repo: [github.com/mansvr/de-plano-a-3d](https://github.com/mansvr/de-plano-a-3d)

1. [Import in Vercel](https://vercel.com/new/clone?repository-url=https://github.com/mansvr/de-plano-a-3d) (Framework: **Other**, build command empty, output **`.`**).
2. Or CLI: `vercel login` then from repo root `vercel --prod`.

Production root redirects to `/v2/`; English hub stays at `/index.html`.
